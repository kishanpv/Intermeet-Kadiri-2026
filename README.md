## Host on GitHub Pages (personal git)
1. Create a repo and copy the contents of `site/` to the repo root (so `index.html` is at the top level).
2. Settings > Pages > Deploy from branch > `main` / root. The link appears after a minute.
3. Share the link on WhatsApp. It opens in Android and iPhone browsers.
Any static host works the same way (Netlify, Cloudflare Pages, etc.): upload the `site/` folder.
